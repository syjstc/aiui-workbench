# AIUI 图片、图集与音频优化

有大量素材的新项目，在确定导出尺寸和资源分组时读本页与同版本官方 `aiui-optimize`。现有项目缩包时，先用官方 Skill 提供的 AIX 审计方法取得实际包体和主要条目。

- **先核对用途。** 用目标视口和实际最大绘制尺寸选导出分辨率。保留源图及生成参数，挑有代表性的图标、半透明边缘、细线和背景对照。对 PNG 调色板、WebP 或其他编码先确认目标 SDK 支持，再比较实际压缩字节、透明边缘、亮度层次和解码耗时。
- **区分包体与解码内存。** RGBA 图片解码占用可用 `宽 × 高 × 4` 粗估，另考虑宿主缓存和多份拷贝。按首屏、共用和场景专属资源组织图集，避免为了少几个文件而在启动时解码大图集。调整图集时同步帧坐标、留边和锚点，在目标倍率下检查串色与抖动。
- **把音效按使用时机准备好。** 对代表性语音、短音效和音乐试不同编码、采样率或声道，核对清晰度、起播时延和目标宿主的解码支持。开跑前准备交互音，场景切换前分批准备下一段素材。检查连续触发、重叠播放与循环边界，保留必要的本地回退。
- **验收正式 AIX。** 用包内实际压缩字节排序，核对动态引用，再用构建规则排除母版、旧图和测试媒体。通过正常打包流程重建并检查条目、最终字节、首屏画面和覆盖相关资源的交互。网络延后加载时另测离线回退、首取与缓存。实时游戏还需 [实际设备帧时间对照](optimization.md)。
