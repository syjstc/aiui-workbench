# AIUI 常见问题

按当前症状选读。具体 API 和验收要求以项目绑定的官方 `aiui-dev` 为准。

| 症状 | 优先处理 |
| --- | --- |
| 已配 MCP，当前聊天仍缺工具 | 分查客户端信任、stdio 握手、服务和聊天缓存。从可用的 `tools/list` 核实，再重连原项目。 |
| 应用行为正确，断言超时 | 核对步骤起点、运行实例和源码版本。将操作与异步响应放在同一步；用显式 reload 观测启动日志。胜负终态、重开和异步响应分别验证。 |
| 点击变长按、单滑跨多项 | 无匹配 keydown 的释放按单击。合并方向别名与同向重复，消费重复事件。使用可信事件时间或扣除首绘阻塞；检查长按释放、反向、再次滑动和返回。 |
| 头部指向覆盖镜腿选择 | 定义输入优先级及重新接管条件。分别验证停头时滑动、重新转头、确认和页面恢复。 |
| 传感器停止后无法重启或画面反向 | 隐藏时清理监听、实例和启动守卫，恢复后取新读数。核对当前宿主的轴向、安装基准与逆相机变换；先区分排队和真正停报。 |
| 语音启动进错应用或打开卡片 | 查看实际 AIX 的工具路由、参数、target 和尺寸。逐段检查 ASR、Agent 匹配及最终打开的 surface。 |
| 模型显示可用但没有有效结果 | 检查实际请求和手机代理，核对结果结构、目标及页面代次。验证用户触发的那条链路；本地降级和模拟回复明确标注。 |
| 相机重试黑屏或旧画面回来 | 用页面可见性和操作代次限制回调；先显示有效原图，后台处理成功再替换。保存失败可重试，删除时先提交索引再清无人引用的媒体。 |
| 音频拒绝参数或退出后继续播放 | 核对当前服务值域和播放器事件。复用播放器，隐藏时取消生成、队列与播放；分别检验请求、播放与听感。 |
| 首屏慢、动画卡或录制掉帧 | 按 [性能优化](optimization.md) 对照计时。录制问题用同一场景录前、录中、录后证实；Canvas 提交与实际呈现分别测量。 |
| 升级后版本、应用身份或数据异常 | 沿用原身份和存储键；按源码版本、构建、安装回读及平台回执逐步核实，未知结果先查原操作。 |

复现后留下最短的「何时触发、怎么处理、验证边界」。个人偏好、项目详情、原始日志与设备记录使用本机经验或项目私有记录。
