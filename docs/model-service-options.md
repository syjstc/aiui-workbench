# 模拟器中的模型与网络服务

普通用户应在真机测试识图、问答、语音等 AI 能力；模拟器界面和默认 `LanguageModel` 错误会提示这一点。网络开关只模拟在线/离线状态，并不提供眼镜/手机服务或任意应用外网访问。

## 当前可用：AI 自动化时临时接管

正在工作的 AI 可以通过 `aiui_ai_configure → aiui_ai_wait → aiui_ai_reply` 接管同一预览的真实 `LanguageModel` 请求。工坊使用 Ink Web SDK 的 `hostCapabilities.languageModel.getConfig()` 配置一个经预览密钥、运行 ID 授权的本机端点，转交文本、图片、上下文和输出格式，回填后应用继续运行。

这条路径仅用于 AI 自己验证应用。默认关闭，不启动额外 AI 进程；监听由本地事件队列阻塞等待，空闲期间不执行模型。普通 MCP 不能主动唤醒空闲聊天。图片必须由实际支持图片输入的 AI 处理，否则明确返回 `device-required`，并由 AI 主动提示用户到真机测试。不得使用固定文本或虚构描述冒充识图。

输入、输出、图片尺寸、次数和有效期都有服务端限制。关闭、源码变化或运行实例改变后取消旧请求，重复或过期回填被拒绝；已完成的图片和提示词从队列内存释放。具体参数及低 token 流程见 [AI 工具工作流](ai-tool-workflows.md#仅供-ai-自动化的模型接管)，或按需读取工坊 Skill 的 `references/simulator-ai.md`。

## 备选：独立模型后端

独立后端可覆盖用户随时操作模拟器的场景，但需要单独配置服务、授权、费用、超时、取消、错误映射和日志。当前没有独立后端配置界面，不推荐将其作为默认开发入口。可通过 SDK 宿主配置和本地代理自行集成，不应把 API Key 放进应用源码或提示词。

| 方式 | 用途 | 边界 |
| --- | --- | --- |
| 当前 AI 临时接管 | AI 自动化时验证文字/图片请求与应用后续行为 | 需要正在执行且支持所需模态的 AI；不证明 Rokid 服务链路 |
| 独立远程或本地模型后端 | 持续的交互式模型服务 | 自行集成、配置和维护；效果、速度、成本取决于后端 |
| 明确标记的固定响应 | 可重复的传输和状态测试 | 不属于真实推理/识图验收 |
| 眼镜＋手机端 Rokid 服务 | 最终用户体验 | 需要设备、手机及服务授权，是推荐验收路径 |

MCP sampling 需要客户端声明支持并授权，不能假设任何已连接的客户端都能响应；当前实现使用普通工具队列，不依赖 sampling。[MCP sampling 规范](https://modelcontextprotocol.io/specification/2025-11-25/client/sampling)

语音识别、朗读和音频合成仍需分别接入对应宿主接口。文本回填不等于验证了语音或设备端流式音频服务。
