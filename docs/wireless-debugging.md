# 无线连接眼镜

**连接眼镜** 提供 **无线连接** 和 **有线连接** 两个同级 Tab，按自己的设备条件选择，工坊会记住所选方式。有线页引导准备数据调试线、在 Rokid AI 开启眼镜 ADB 调试、插线并授权；无线页按下面的步骤连接。安装和操作说明共用，设备检查与安装目标按当前 Tab 区分。

使用无线时，让眼镜和电脑连接同一个 Wi-Fi 或手机热点。打开 **连接眼镜 → 无线连接**，在自己的设备旁点 **一键连接眼镜**。眼镜弹出调试授权时，选择「允许」。工坊会核实无线连接，并继续检查 AIUI 运行环境。

## 首次配对

工坊先从当前网络查找已经开放调试的设备。通常只需点击自己的设备，在眼镜弹出调试授权时选择「允许」。有多台设备时，工坊会列出可选目标。

## 用手机安装无线助手

在 **连接眼镜 → 用手机安装无线助手** 打开下载码。主动查找后仍没有发现设备时，工坊也会直接显示这个码。

1. **手机和电脑**连同一个 Wi-Fi，用手机相机扫码，点「下载 APK」。下载页会显示带版本号的文件名，在工具箱选这个文件。
2. 在手机打开 **Rokid AI → 工具箱 → 眼镜应用管理 → 安装新应用**，从手机的「下载」中选刚下载的 APK。
3. 在眼镜应用列表打开 **AIUI 无线助手**。若提示「打开设备信息」，滑动镜腿，让焦点框移到显示助手所示构建编号的「版本号」，再连点 7 次，返回助手。看到时钟时，返回设备信息找「版本号」。点 **打开无线调试**，若开关已开启，直接选「使用配对码配对设备」。部分固件会进入「开发者选项」，这时先滑动，看着焦点框移到「无线调试」这一行再点，保留顶部总开关开启。手机工具箱的遥控器也能操作眼镜。[Rokid 工具箱说明](https://global.rokid.com/pages/faq)
4. **眼镜与电脑**保持在能相互访问的网络。在工坊填入六位数字。无法自动发现时填入配对窗口的地址，配对后若仍未连上，再填写无线调试主页的连接地址和端口。[Android 无线调试说明](https://developer.android.com/studio/run/device#wireless)

下载页来自当前电脑。工坊优先显示局域网网卡的地址，也可以切换其他地址或从电脑传送 APK。下载码十分钟后过期，可以重新生成。

下载页跟随工坊当前的中文或英文，不受手机浏览器语言影响。下载 APK 后还需要在 Rokid AI 完成安装；页面会接着说明遥控器、开启调试及回到电脑配对的步骤。

## 二维码配对

在工坊选择 **二维码配对**，再用眼镜 **无线调试 → 使用二维码配对设备** 的扫码入口扫描工坊上的码。工坊按 [Android 的 ADB 二维码协议](https://android.googlesource.com/platform/packages/modules/adb/+/refs/heads/main/docs/dev/adb_wifi.md#pair-with-qr-code) 生成临时凭据，只连接本会话对应的配对服务。二维码两分钟内有效，离开页面、改用六位码或清空连接时停止等待。

**手机下载码**用手机相机扫描，只负责下载助手 APK；**配对二维码**需要眼镜的系统扫码入口扫描，手机不能替眼镜配对。具体固件没有扫码入口，或网络无法发现扫码服务时，使用六位配对码。二维码流程已做模拟服务验证，真实眼镜扫码仍需在支持该入口的固件上确认。

## 连接后安装和操作

- **AIUI 项目**：在工坊选择项目，点 **安装到眼镜**，完成后点 **在眼镜上打开**。
- **其他 Android APK**：把 APK 下载到手机，打开 **Rokid AI → 工具箱 → 眼镜应用管理 → 安装新应用**，选择该文件。
- **手机遥控**：打开 **Rokid AI → 工具箱 → 遥控器**。滑动移动焦点，点击确认，返回键退回上一页；也可使用眼镜镜腿。

无线助手会用紧凑布局打开 RG 眼镜的设备信息和手动开发者选项页，「版本号」可以完整滚入屏幕。工坊已连接这副眼镜时，从工坊打开设置或使用交互投屏，系统设置也会自动显示镜腿或遥控器当前选中的一行。首次纯无线配对时，固件自己打开的无线调试子页仍使用系统布局。有已授权的调试线时，可以直接在工坊点「一键切换无线」。

## 固件或网络受限时

- **固件只支持有线开启网络调试**。接上支持数据传输的调试线并允许调试，点「一键切换无线」。等工坊确认无线连接后拔线。
- **访客 Wi-Fi 或公司网络隔离了设备**。让眼镜与电脑接入允许互访的网络，例如同一个手机热点。系统提示本地网络权限时，允许工坊访问。

## 后续使用

工坊记住已确认在线的地址和设备身份，不保存配对码。保持工坊打开，会在连接检查时自动发现服务并重试已记住的眼镜。可发现的服务更换端口后，工坊使用新地址；身份不一致时停止自动重连。平时只查询已发布的服务和本机邻居缓存。用户主动查找且未发现服务时，工坊会在小型直连 IPv4 网络上验证标准旧式 ADB 端口。大网、组播受限或自定义未发布端口可填写眼镜显示的当前地址。

“移除记录”只清除工坊记录，不打断现有连接或撤销设备端信任。需要撤销配对时，在眼镜的已配对设备中移除这台电脑。

## 一键清空与首次配对

“其他连接方式与清空记录”底部的“一键清空”清空工坊保存的无线设备、重试状态及表单，并断开这些眼镜的无线连接。不会删除项目、应用、Wi-Fi 或电脑的全局 ADB 密钥，也不会断开无关设备。

要完整重走首次配对，先选择眼镜并勾选“完整重走首次配对”，再点“一键清空”。工坊使用眼镜现有系统权限调用 Android 的授权管理接口，撤销所选眼镜对**所有电脑**的 ADB 授权，并让该眼镜的现有 USB 会话重新授权。不依赖 root，不安装常驻应用，也不修改电脑全局密钥。重置后由你重新连接，工坊不会自动替你授权或配对。

固件不提供对应接口、权限不足或眼镜离线时，页面会明确提示尚未撤销成功，需要在眼镜端忘记电脑或撤销调试授权。不能将仅清空工坊记录当作系统配对已撤销。

## 需要补做的情况

| 页面提示 | 下一步 |
| --- | --- |
| 眼镜尚未连接 Wi-Fi | 使用眼镜支持的网络设置或联网方式，让眼镜和电脑连接同一网络，再点击“一键切换无线” |
| 配对完成，但尚未连接 | 返回眼镜的无线调试主页，填写连接地址；配对窗口的端口不能代替连接端口 |
| 自动发现不可用 | 手动输入地址；配对表单也可同时填写配对地址和连接地址 |
| 换网络、重启后断开 | 保持工坊打开等待重连；地址已变且无法发现时重新输入。通过 USB 开启的网络调试可能需要再次插线开启 |
| 端口可达但 ADB 仍报无路由，或提示旧版后台 | 先结束其他工具的调试、安装、投屏和录制，再在“连接不上时怎么做？”中点击“重启连接工具”；会短暂断开本机所有 ADB 连接 |
| 连接拒绝或超时 | 核对当前无线调试开关、地址和同一网络；避免隔离设备的访客网络，检查本地网络权限、VPN 和防火墙 |

## MCP / CLI

桌面、Web、MCP 和共享 CLI 使用同一服务及记录：

- `aiui_adb_discover`：返回自动发现的配对/连接地址、已记住设备及重连提示。
- `aiui_connection_guide({step, locale, shareHelper?})`：检查当前连接状态，返回 `overview/install/pair/ready` 对应的步骤及中英文工坊操作示例截图。`shareHelper:true` 生成手机下载页和下载码；示例截图不能当作当前设备已在线的证据。
- `aiui_adb_pair_qr({action: "start" | "status" | "cancel", id?})`：生成并展示眼镜配对二维码；在两分钟有效期内查询同一会话，结束后取消，不无限轮询。MCP 原生返回图片。
- `aiui_adb_connect({address, pairingCode?, connectAddress?})`：连接或配对后续连。只有 `connected: true` 表示已确认在线；`paired: true, connected: false` 时按 `message` 完成连接。
- `aiui_adb_wireless_enable({serial})`：将指定已授权 USB 设备切为无线；缺少 Wi-Fi 时返回 `nextStep: "wifi"`。
- `aiui_adb_saved({recordId, action: "reconnect" | "forget"})`：重连或移除记录。
- `aiui_adb_reset({revokeAuthorization?, serial?})` 清空工坊无线记录。完整重试时传 `revokeAuthorization: true` 和所选眼镜的序列号。有同一副眼镜的已授权 USB 通道时，工坊先断开无线连接，再撤销授权并回读数量。`requiresUsbUnplug` 提示拔线，`requiresDeviceAction` 表示还需在眼镜端忘记这台电脑，或在开发者选项中确认撤销调试授权。

无线连接不会改变项目、应用身份或设备上的已保存进度。
