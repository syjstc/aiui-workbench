# 官方资料库

“官方资料”沿用对应快照里的官方目录，按指南、框架、组件、API、教程等层级展开。开发 Skill、代码示例、补充资料和另一语言的文档也能从目录找到。目录一次载入全部资料元数据；展开分组不需要同步或逐页加载。打开长文时自动读取完整正文，右侧“本文目录”可定位章节。

## 搜索全部内容

搜索在本地完整快照里查找标题、章节、正文、路径和代码示例，包括没有打开或显示在目录中的文档，也包括长文后半部分。当前内置快照包含 468 份资料；同步之后会按实际资料数量搜索。

可搜索 API 标识符，也可用常见中英文词或简短问题，例如 `getUserMedia`、`如何调用摄像头拍照`、`怎么语音播报`。搜索会分词、忽略提问辅助词，并匹配常见中英文 API 名称；多个检索概念需要同时命中。标题和章节优先排序，结果显示高亮摘要、所在目录与命中章节，点击后自动定位。搜索在离线状态下运行，无需配置模型或 API 密钥。

## 自动更新

默认每天检查官方仓库一次，服务启动时补查到期的更新。可以在文档页改成每周更新或仅手动更新；设置会保存。服务运行期间每分钟检查是否到期，电脑休眠后或服务重新启动时会补查。

只有上游版本变化才下载新的文档快照。新快照完整性校验完成后才切换当前版本，并更新目录与搜索。更新失败保留现有离线资料，一小时后重试；文档页显示最近检查时间和失败提示。已有项目绑定的资料版本和阅读历史仍保留原快照。

## 文档图片

正文直接显示官方配图，点击图片可以放大，按 Esc 或点击遮罩关闭。图片与文档使用相同的仓库快照；下载时核对 Git blob 摘要并缓存到本地。当前内置快照的 81 张文档配图已打包，首次使用也能离线查看。

后续同步同时缓存新文档引用的图片。某张图片下载失败不会使已验证的文档不可用；图片位置显示重试入口，再次同步也会补齐缺失图片。

## MCP / CLI

- `aiui_docs_catalog`：完整目录树和全部资料的元数据。
- `aiui_docs_search`：完整资料库的全文检索。返回 `documents`、`total`、`searchedDocuments` 和 `nextOffset`；每条结果包含 `fragment`、`heading`、`excerpt`、`matchedTerms`、版本与来源。`offset` / `limit` 可控制分页，桌面和 Web 一次显示全部命中结果。
- `aiui_docs_read`：分段读取，支持官网链接、相对链接和章节锚点。桌面和 Web 自动读取后续分段。
- `aiui_docs_image`：读取某篇文档引用的图片，参数为 `path`、`from` 和可选的 `revision`。
- `aiui_docs_settings`：设置 `autoUpdate` 和 `intervalHours`（24 或 168）。
- `aiui_docs_sync`：立即检查并同步，返回可等待、可取消的任务。

更新仓库内的离线图片包可运行 `npm run prepare:doc-images`，它只为现有固定快照补齐图片，不改变文档版本。
